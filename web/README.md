# Autocue Web

Vite + React + TypeScript dual-deck app. Brand: Void Black / Acid Lime / Violet Pulse / Fog Gray.

```bash
npm install
npm run dev
npm run build
```

Components: Deck, Waveform, Transport, Crossfader, StemPanel, SetlistStrip, TrackBadge. Web Audio oscillators for feedback. Streaming tracks are cue-only; Local/Demo are mix-ready.
